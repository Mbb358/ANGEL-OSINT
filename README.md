# ANGEL v2.0

OSINT-сканер для поиска информации по номеру телефона, Telegram-username и IP-адресу.

&gt; ⚠️ **Используйте только в законных целях и с согласия субъекта данных.**  
&gt; Автор не несёт ответственности за незаконное применение инструмента.

---

## Возможности

- 📱 **Телефон** — оффлайн-данные (страна, оператор, регион), поиск упоминаний, утечки
- 💬 **Username** — профиль Telegram, упоминания в Яндексе, ссылки на 20+ соцсетей
- 🌐 **IP-адрес** — геолокация, Shodan, Whois, ICMP-ping
- 🛡️ **Безопасность** — блокировка приватных IP, защита от command injection
- 💾 **История** — SQLite-база сканирований
- ⚙️ **Конфиг** — прокси, таймауты, retry через INI-файл
